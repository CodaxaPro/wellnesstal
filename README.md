# Wellnesstal v2

Premium wellness site — **built from scratch** (Antara-level design, Wellnesstal content).

- No admin panel
- No Supabase
- Single content file: `content/site.json`

## Pages

- `/` — Homepage
- `/headspa` — Headspa packages + Treuepay booking
- `/gutschein` — Gift voucher embed
- `/impressum` / `/datenschutz`

## Dev

```bash
npm install
npm run dev
```

Open http://localhost:3001
